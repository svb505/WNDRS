##About
**WinDoors52** this is an operating system simulator written in **Python**, with some of the logic also written in **C++**. The program fully replicates the interface and functionality of a real OS, including a file manager, browser, settings, sound, utilities, logs, and much more. The OS also has a wide range of games and other user utilities.
The OS simulator uses a GitHub Gist to store some data. **The data is stored in a private repository and is visible only to the developer.**

In this moment, project count >36k lines of code(with the games and others utilits)
